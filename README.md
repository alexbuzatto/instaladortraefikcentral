# instaladortraefikcentral

Gerenciador de instalação do Traefik Central com suporte a Wildcards e TLS Passthrough.

## Instalação Rápida

Para rodar o instalador diretamente do GitHub em qualquer servidor Linux, use o comando:

```bash
curl -sSL https://raw.githubusercontent.com/alexbuzatto/intaladortraefikcentral/main/traefikcentral.sh | sudo bash
```
